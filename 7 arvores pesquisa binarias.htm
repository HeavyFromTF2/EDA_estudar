O que é uma BST (Binary Search Tree)?

É uma árvore binária onde cada nó tem, no máximo, dois filhos. A grande diferença para uma árvore comum é a sua Regra de Ouro Matemático (Slide 4):

Seja x um nó qualquer da árvore. Se y for um nó na subárvore esquerda de x, então y.key ≤ x.key. Se y for um nó na subárvore direita de x, então y.key ≥ x.key.

Traduzindo para miúdos: Quem se senta à esquerda do pai tem de ser mais pequeno ou igual. Quem se senta à direita tem de ser maior ou igual. Se isto for respeitado, o computador consegue pesquisar dados muito rapidamente sem ler a árvore toda.

Os Atributos de Cada Nó (O que significa cada letra?)

  • x.key: O valor numérico real guardado no nó (ex: 15).
  • x.p: O Progenitor (Pai) do nó. Se for a Raiz da árvore, o pai é NIL (vazio).
  • x.left: O ponteiro para o filho da esquerda.
  • x.right: O ponteiro para o filho da direita.

Nota de Exame (Slide 5): A altura da árvore determina o custo de todas as operações. No melhor cenário (árvore perfeitamente equilibrada), o custo é O(log n). No pior cenário (árvore torta em linha reta), o custo passa a ser O(n), virando uma simples lista ligada!

Pesquisas, Mínimos, Máximos e Caminhamentos

O PDF aborda as rotinas fundamentais de consulta e a forma como visitamos os nós (Caminhamento em-ordem / Inorder-Tree-Walk).

INORDER-TREE-WALK(x) (Slide 6) 
1  if x != NIL // Caso base: se chegar a NIL, para a recursão
2      INORDER-TREE-WALK(x.left)  // Visita toda a subárvore esquerda
3      print x.key                // Imprime a chave do nó atual
4      INORDER-TREE-WALK(x.right) // Visita toda a subárvore direita
// Nota de exame: Imprime os elementos por ordem crescente!
TREE-SEARCH(x, k) (Slide 7) 
1  if x == NIL or k == x.key // Caso base: chegou ao fim ou achou a chave
2      return x                 // Para se não achar ou se encontrar
3  if k < x.key // Chave procurada é menor: descer à esquerda
4      return TREE-SEARCH(x.left, k)  // Chave menor: vai p/ esquerda
5  else // Chave procurada é maior: descer à direita
6      return TREE-SEARCH(x.right, k) // Chave maior: vai p/ direita
TREE-MINIMUM(x) (Slide 11) 
1  while x.left != NIL // Desce enquanto houver filho esquerdo
2      x = x.left  // Desce o máximo possível para a esquerda
3  return x        // O nó mais à esquerda é o menor valor
TREE-MAXIMUM(x) (Slide 11) 
1  while x.right != NIL // Desce enquanto houver filho direito
2      x = x.right // Desce o máximo possível para a direita
3  return x        // O nó mais à direita é o maior valor

Como se insere um elemento novo? (TREE-INSERT)

Para meter um nó novo na árvore, tu nunca o metes no meio. Tu corres a árvore desde a raiz usando dois ponteiros (o ponteiro de exploração x e o ponteiro "atrás do pai" y) até encontrares um espaço vazio (NIL). É aí que ele é anexado.

TREE-INSERT(T, z) (Slide 14) 
1  y = NIL         // y vai guardar o futuro pai de z
2  x = T.root      // Começamos a varredura a partir da raiz da árvore
3  while x != NIL  // Descemos pela árvore até bater em NIL (folha)
4      y = x       // Guarda a posição atual de x antes dele descer
5      if z.key < x.key // Chave menor: caminha para a esquerda
6          x = x.left   // Se a nova chave for menor, caminha para a esquerda
7      else // Chave maior ou igual: caminha para a direita
8          x = x.right  // Se for maior ou igual, caminha para a direita
9  z.p = y         // Definimos o pai de z como sendo o y encontrado
10 if y == NIL // A árvore estava completamente vazia
11     T.root = z  // Se a árvore estava vazia, z torna-se a própria raiz
12 else if z.key < y.key // z é menor que o pai encontrado: encaixa à esquerda
13     y.left = z  // Encaixa z como filho esquerdo do pai
14 else // z é maior ou igual: encaixa à direita
15     y.right = z // Encaixa z como filho direito do pai

A Remoção e a Sub-rotina TRANSPLANT

Remover um nó z exige gerir os ponteiros com cuidado. O professor utiliza uma função de suporte chamada TRANSPLANT para substituir uma subárvore pela outra, facilitando os 3 cenários de eliminação estudados (Slide 17).

TRANSPLANT(T, u, v) (Slide 18) 
1  if u.p == NIL // Se u não tem pai, é a raiz da árvore
2      T.root = v      // Se u era a raiz, v passa a ser a nova raiz
3  else if u == u.p.left // u era filho esquerdo do seu pai
4      u.p.left = v    // Se u era filho esquerdo, substitui pelo v
5  else // u era filho direito do seu pai
6      u.p.right = v   // Se u era filho direito, substitui pelo v
7  if v != NIL // Só atualiza o pai de v se v não for NIL
8      v.p = u.p       // Atualiza o ponteiro do pai de v para o pai de u
TREE-DELETE(T, z) (Slide 19) 
1  if z.left == NIL // Cenário A: z não tem filho esquerdo
2      TRANSPLANT(T, z, z.right) // Cenário A/B: só tem filho direito
3  else if z.right == NIL // Cenário B: z tem só filho esquerdo
4      TRANSPLANT(T, z, z.left)  // Cenário B: só tem filho esquerdo
5  else // Cenário C: z tem dois filhos
6      y = TREE-MINIMUM(z.right) // Cenário C: Acha sucessor y no lado direito
7      if y.p != z               // Se o sucessor não for filho direto de z
8          TRANSPLANT(T, y, y.right) // y liberta-se da sua posição antiga
9          y.right = z.right     // O filho direito de z passa para y
10         y.right.p = y         // Atualiza progenitor
11     TRANSPLANT(T, z, y)       // Coloca y no lugar de z
12     y.left = z.left           // Transfere o filho esquerdo de z para y
13     y.left.p = y              // Atualiza progenitor do filho esquerdo

TREE-SUCCESSOR e TREE-PREDECESSOR (Slide 12)

Estes algoritmos servem para encontrar, respetivamente, o elemento imediatamente a seguir e o elemento imediatamente antes de um nó x, na ordem crescente da árvore (a mesma ordem que um INORDER-TREE-WALK visitaria). Ambos correm em O(h) — a mesma ordem de grandeza da altura da árvore, tal como a pesquisa, o mínimo e o máximo.

TREE-SUCCESSOR(x) tem 2 casos:
1. Se x tem subárvore direita (x.right ≠ NIL): o sucessor é simplesmente o mínimo dessa subárvore direita (desce sempre à esquerda a partir de x.right).
2. Se x não tem subárvore direita: sobe-se pelos antepassados de x até encontrar o primeiro nó y do qual x é filho esquerdo — ou seja, sobe enquanto x for filho direito do seu pai.
TREE-SUCCESSOR(x) 
1  if x.right != NIL // Caso 1: tem subárvore direita?
2      return TREE-MINIMUM(x.right) // O sucessor é o mínimo dessa subárvore
3  y = x.p
4  while y != NIL and x == y.right // Caso 2: sobe enquanto for filho direito
5      x = y
6      y = y.p
7  return y // Primeiro antepassado do qual x é filho esquerdo
TREE-PREDECESSOR(x) é o espelho exato:
1. Se x tem subárvore esquerda: o predecessor é o máximo dessa subárvore esquerda.
2. Caso contrário: sobe-se enquanto x for filho esquerdo do seu pai, até encontrar o primeiro antepassado do qual x é filho direito.

Exemplo com a árvore usada nesta página (raiz 15)

Sucessor de 13: 13 não tem filho direito → sobe: pai é 7 (13 é filho direito de 7, continua a subir) → pai de 7 é 6 (7 é filho direito de 6, continua) → pai de 6 é 15, e 6 é filho esquerdo de 15 → o sucessor de 13 é 15.

Sucessor de 6: 6 tem subárvore direita (7, com filho 13) → desce sempre à esquerda a partir de 7: 7 não tem filho esquerdo → o sucessor de 6 é 7.
