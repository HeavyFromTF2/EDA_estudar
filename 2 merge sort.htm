Merge Sort — Demonstração Interativa

Abordagem Incremental vs. Divisão e Conquista (Slide 3)

O Insertion Sort segue uma abordagem incremental: ordena o array crescendo uma solução parcial, um elemento de cada vez. O Merge Sort segue uma abordagem diferente, Divisão e Conquista, com 3 passos: Dividir o problema em subproblemas mais pequenos e semelhantes ao original; Resolver os subproblemas recursivamente (ou diretamente, se forem pequenos o suficiente); Combinar as soluções dos subproblemas na solução do problema original.

Teorema Principal / Master Theorem (Slides 24-25)

Serve para resolver recorrências do tipo T(n) = a·T(n/b) + f(n), onde a ≥ 1 e b > 1 são constantes e f(n) é uma função assintoticamente positiva. Compara-se f(n) com n^(log_b a):

Caso 1: se f(n) = O(n^(log_b a − ε)) para alguma constante ε > 0, então T(n) = Θ(n^(log_b a)). (o custo da recursão domina)
Caso 2: se f(n) = Θ(n^(log_b a)), então T(n) = Θ(n^(log_b a) · log n). (f(n) e a recursão "empatam")
Caso 3: se f(n) = Ω(n^(log_b a + ε)) para alguma constante ε > 0, e se a·f(n/b) ≤ c·f(n) para alguma constante c < 1 (condição de regularidade), então T(n) = Θ(f(n)). (f(n) domina o custo)

Aplicação ao Merge Sort

A recorrência do Merge Sort é T(n) = 2T(n/2) + Θ(n), logo a = 2, b = 2, f(n) = Θ(n). Calculando n^(log_b a) = n^(log₂ 2) = n¹ = n. Como f(n) = Θ(n) coincide com n^(log_b a) = n, aplica-se o Caso 2, e o resultado é T(n) = Θ(n^(log₂ 2) · log n) = Θ(n log n) — o mesmo resultado que se obtém pela árvore de recursão, mas de forma direta e formal.

Secção 2: MERGE(A, p, q, r) — Combinação e Escrita das Metades
1n1 = q - p + 1// Tamanho da sequência da esquerda.
2n2 = r - q// Tamanho da sequência da direita.
3let L[1..n1+1] and R[1..n2+1] be new arrays// Aloca os blocos temporários L e R.
4for i = 1 to n1 do L[i] = A[p + i - 1]// Transpõe a sub-sequência esquerda para L.
5for j = 1 to n2 do R[j] = A[q + j]// Transpõe a sub-sequência direita para R.
6L[n1 + 1] = ∞// Sentinela estável no final de L.
7R[n2 + 1] = ∞// Sentinela estável no final de R.
8i = 1; j = 1// Inicializa os apontadores de leitura.
9for k = p to r do// Reconstrói e ordena o intervalo no Array Principal A.
10 if L[i] <= R[j] then// Se o valor em L for o menor...
11 A[k] = L[i]; i = i + 1// Aloca-o em A[k] e avança em L.
12 else A[k] = R[j]; j = j + 1// Senão, aloca R[j] em A[k] e avança em R.
